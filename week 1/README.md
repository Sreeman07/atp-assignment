# JavaScript Practice Programs

This repository contains basic JavaScript programs for practicing arrays, functions, loops, conditions, and objects.

## Topics Covered

- Array operations using `splice()`, `filter()`, and `find()`
- Object manipulation
- Finding biggest number using conditions
- Functions with arguments
- Array sum calculation
- Searching elements in an array
- Loop practice programs

---

## Programs Included

### 1. Employee Array Operations
Performed operations on employee data:
- Inserted a new employee at 2nd position
- Removed employee named "Kiran"
- Updated Sneha's last mark from 95 to 75

### 2. Find Bigger Number Between Two Numbers
Compared two numbers using `if-else`.

### 3. Find Biggest Among Three Numbers
Used conditions to find the largest number.

### 4. Function to Return Biggest Number
Created a function that accepts 3 numbers and returns the biggest number.

### 5. Sum of Array Elements
Calculated total sum of elements in an array using loop.

### 6. Search Element in Array
Checked whether a target element exists in the array.
