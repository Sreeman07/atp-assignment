# HTML Practice Web Pages

This project contains simple HTML practice pages created for learning basic web development concepts.

## Files Included

### 1. index.html
This page includes:
- Headings
- Paragraphs
- Google link
- Unordered list of fruits

### 2. cat.html
This page includes:
- Introduction about "Pochi The Cat"
- Image using `<img>` tag
- Ordered list
- Links using `<a>` tag
- Horizontal line using `<hr>`

---

## Topics Practiced

- Basic HTML structure
- Headings (`<h1>` to `<h3>`)
- Paragraphs (`<p>`)
- Lists (`<ul>`, `<ol>`)
- Links (`<a>`)
- Images (`<img>`)
- HTML page formatting
